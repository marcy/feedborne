# feedborne

[![CI](https://github.com/marcy/feedborne/actions/workflows/ci.yml/badge.svg)](https://github.com/marcy/feedborne/actions/workflows/ci.yml)

A small RSS reader written in Go.

- Single binary with subcommands: `crawl` fetches feeds, `serve` runs the web UI
- Storage: SQLite (pure-Go driver, no cgo)
- Frontend: server-rendered HTML with templ (type-safe, compiled to Go) + htmx (vendored, no CDN) for partial updates and a pinch of vanilla JS for the keyboard UI.
- Keyboard-driven reading: `j` / `k` move the selection, `o` opens the entry in a new tab (and marks it read)

## Development

All the toolchains are pinned with [mise](https://mise.jdx.dev) in `mise.toml` (Go, sqlc, templ and Task):

```sh
mise install   # install every pinned tool
task build     # generate + build with the mise-managed tools
```

## Usage

Common workflows are in the Taskfile:

```sh
task build   # sqlc + templ generate, then go build
task test    # run the tests
task crawl   # fetch all registered feeds
task serve   # run the web UI (http://127.0.0.1:8080)
task dev     # crawl, then serve
```

Or drive the binary directly:

```sh
go build -o feedborne .

# register a feed (nothing is registered by default)
./feedborne feed add https://example.com/feed.rss
./feedborne feed list

# fetch all registered feeds
./feedborne crawl

# read
./feedborne serve -addr 127.0.0.1:8080
```

## Layout

- `main.go` — subcommand dispatch
- `crawl.go` — fetching (ETag / Last-Modified aware) and parsing via gofeed
- `store.go` — thin wrapper over the sqlc-generated queries
- `server.go` — HTTP handlers (full page, htmx fragments, static files)
- `views.templ` — templ components (page, entry, feeds bar, load-more); `views_templ.go` is generated
- `static/` — htmx 2.x (vendored), stylesheet and the keyboard script, embedded in the binary
- `db/schema.sql`, `db/queries.sql` — SQL sources for sqlc
- `internal/db/` — code generated by sqlc (do not edit by hand)
- `*_test.go` — tests for the store, the crawler and the HTTP handlers

## Regenerating code

```sh
task generate   # sqlc (internal/db/) + templ (views_templ.go)
```
